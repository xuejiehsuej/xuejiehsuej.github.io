# 美术与实现记录

## 确定方向

整体采用工业宇宙与水墨的结合；背景为大型天体与群星，Index / Life 加强平面设计。保留强信息层级、图形与内容协同位移、多层转场，正文置于低干扰区域。

Home 为黑洞吸积盘；Works 为环行星；Experience 为月面弧；Life 为柔和巨行星。人物使用原创生成的六角色图集，通过 CSS luminance mask 呈现单色轮廓。

## 继承与重建

- v3：首页卡片真实 flex 扩张、反色与相邻挤压，圆形保持 1:1。
- v4 Works：项目轨道持续存在；旧内容退让、拼色侵入、新内容推进。重新实现为串行异步状态控制，避免多组定时器交错。
- 原始参考录屏：Experience 的持续路线、巨大弧面、人物锚点、大字与碎片推进。
- 星魂参考截图：不规则分片与发光边缘。水晶背面展示不同人物，外层命中面不绘制矩形。
